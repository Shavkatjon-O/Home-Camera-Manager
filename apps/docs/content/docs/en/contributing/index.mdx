## Developing without cameras

The development kit in tools/devkit stands in for a real site. Its simulated camera image answers ONVIF and WS-Discovery like an IP camera and serves looping video files over RTSP, and several of them on one network form a site that discovery finds; the catalog's Simulated entry matches them. A whole simulated site with seed data follows. <Status kind="planned" /> Video files are mounted at run time and never enter the repository.

## Documentation

This site lives in apps/docs. Pages are MDX files under apps/docs/content/docs; the camera, configuration, API, analytics contract, architecture and changelog pages are generated from the repository when the site is built, so change their sources, not the pages. apps/docs/README.md describes running it.
